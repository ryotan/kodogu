# crypto

開発者向けの暗号化ツールライブラリ。ファイルや文字列の暗号化/復号、署名/検証機能を提供し、暗号化機能の開発を支援する。

## ユーザーストーリー

- [x] 開発者として、RSA/ECDSA/Ed25519の鍵ペアを生成したい
- [x] 開発者として、RSA公開鍵で文字列を暗号化したい（ECDSA/Ed25519は署名専用のため暗号化不可）
- [x] 開発者として、RSA秘密鍵で暗号化されたデータを復号したい
- [x] 開発者として、対称鍵で文字列を暗号化/復号したい
- [ ] 開発者として、対称鍵でファイルを暗号化/復号したい（専用APIは未実装）
- [ ] 開発者として、秘密鍵でデータに署名したい
- [ ] 開発者として、公開鍵で署名を検証したい
- [ ] 開発者として、クレデンシャルストアを選択したい（パスワードベース暗号化ファイル、OSセキュアストレージ、1Password）

## 機能要件

### 鍵ペア生成

- [x] RSAアルゴリズムサポート（2048, 4096ビット）
- [x] ECDSAアルゴリズムサポート（P-256, P-384）
- [x] Ed25519アルゴリズムサポート
- [x] PEM形式での出力
- [ ] DER形式での出力

### 暗号化/復号

- [x] AES-128-GCM/AES-256-GCM対称暗号
- [x] RSAハイブリッド暗号（RSA + AES-256-GCM）
- [x] 文字列の暗号化/復号
- [ ] ファイルの暗号化/復号（専用APIは未実装、Plaintext経由で技術的には可能）
- [ ] ストリーミング暗号化（大容量ファイル対応）

### 署名/検証

- [ ] RSA-SHA256署名
- [ ] ECDSA署名
- [ ] Ed25519署名
- [ ] 文字列への署名/検証
- [ ] ファイルへの署名/検証

### 鍵管理

- [x] 非対称鍵ペアの生成（PEM形式で出力）
- [x] 対称鍵のランダム生成（AES-128/AES-256）
- [x] パスワード風文字列の生成（英数字）
- [x] PBKDF2-HMAC-SHA256による鍵導出
- [ ] 非対称鍵のインポート（PEM形式から読み込むドメインAPI）
- [ ] 非対称鍵のエクスポート（ドメインオブジェクトからPEM形式へ変換するAPI）
- [ ] 対称鍵のインポート（UTF-8文字列またはBase64からの変換API）
- [ ] 対称鍵のエクスポート（UTF-8文字列またはBase64への変換API）
- [ ] クレデンシャルストア選択
  - [ ] パスワードベース暗号化ファイル
  - [ ] OSセキュアストレージ
  - [ ] 1Password連携

## 非機能要件

- Rustライブラリとして実装
- CLI/GUIから利用可能な設計
- テスト可能な構造（Clean Architecture）

## スコープ外

- 証明書管理（certificate-contextの責務）
- ネットワーク通信
