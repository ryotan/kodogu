# crypto

開発者向けの暗号化ツールライブラリ。ファイルや文字列の暗号化/復号、署名/検証機能を提供し、暗号化機能の開発を支援する。

## ユーザーストーリー

- [x] 開発者として、RSA/ECDSA/Ed25519の鍵ペアを生成したい
- [x] 開発者として、公開鍵で文字列を暗号化したい
- [x] 開発者として、公開鍵でファイルを暗号化したい
- [x] 開発者として、秘密鍵で暗号化されたデータを復号したい
- [x] 開発者として、対称鍵で文字列/ファイルを暗号化/復号したい
- [ ] 開発者として、秘密鍵でデータに署名したい
- [ ] 開発者として、公開鍵で署名を検証したい
- [ ] 開発者として、クレデンシャルストアを選択したい（パスワードベース暗号化ファイル、OSセキュアストレージ、1Password）

## 機能要件

### 鍵ペア生成

- [x] RSAアルゴリズムサポート（2048, 4096ビット）
- [x] ECDSAアルゴリズムサポート（P-256, P-384）
- [x] Ed25519アルゴリズムサポート
- [x] PEM形式での出力
- [ ] DER形式での出力

### 暗号化/復号

- [x] AES-128/AES-256対称暗号
- [x] RSAハイブリッド暗号（RSA + AES）
- [x] 文字列の暗号化/復号
- [x] ファイルの暗号化/復号
- [ ] ストリーミング暗号化（大容量ファイル対応）

### 署名/検証

- [ ] RSA-SHA256署名
- [ ] ECDSA署名
- [ ] Ed25519署名
- [ ] 文字列への署名/検証
- [ ] ファイルへの署名/検証

### 鍵管理

- [x] 非対称鍵のインポート（PEM形式）
- [x] 非対称鍵のエクスポート（PEM形式）
- [x] 対称鍵のランダム生成（AES対称鍵/パスワード風文字列）
- [x] 対称鍵のインポート（UTF-8文字列またはBase64エンコードAES鍵）
- [x] 対称鍵のエクスポート（UTF-8文字列またはBase64エンコードAES鍵）
- [x] 文字列鍵使用時のオプション（PBKDF2導出/UTF-8バイト列直接使用）
- [ ] クレデンシャルストア選択
  - [ ] パスワードベース暗号化ファイル
  - [ ] OSセキュアストレージ
  - [ ] 1Password連携

## 非機能要件

- Rustライブラリとして実装
- CLI/GUIから利用可能な設計
- テスト可能な構造（Clean Architecture）

## スコープ外

- 証明書管理（certificate-contextの責務）
- ネットワーク通信
